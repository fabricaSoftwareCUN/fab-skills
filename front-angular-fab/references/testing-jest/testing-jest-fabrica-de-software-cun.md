# Testing Jest Fabrica de Software CUN

## Objetivo

Unificar practicas de pruebas unitarias en Angular con Jest y criterios de calidad verificables.

## Instrucciones

- Leer implementacion antes de crear pruebas.
- Cubrir casos de exito, error y casos negativos.
- Usar mocks tipados y deterministas.
- Validar renderizado cuando exista comportamiento visual.
- Resolver todas las solicitudes HTTP en pruebas.

## Reglas

- No usar configuraciones de testing deprecadas.
- No mezclar implementaciones reales con mocks sin control.
- No dejar pruebas no deterministas o con requests pendientes.
